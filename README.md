# Конфигурационное управление

Учебный проект по предмету «Конфигурационное управление».

Эмулятор командной оболочки UNIX-подобной ОС с виртуальной файловой системой (VFS).

**Вариант №8**

## Описание

Программа представляет собой эмулятор командной оболочки (shell), работающий в режиме REPL.
Все операции выполняются в виртуальной файловой системе, загружаемой из XML-файла.

## Этапы разработки

- **Этап 1.** REPL — минимальный прототип
- **Этап 2.** Конфигурация — параметры командной строки
- **Этап 3.** VFS — виртуальная файловая система (XML)
- **Этап 4.** Основные команды: ls, cd, uname, tac
- **Этап 5.** Дополнительные команды: mv
