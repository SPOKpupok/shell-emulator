# Конфигурационное управление

Учебный проект по предмету «Конфигурационное управление».
Эмулятор командной оболочки UNIX-подобной ОС с виртуальной файловой системой (VFS).

**Вариант №8**

## Описание

Программа представляет собой эмулятор командной оболочки (shell), который:
- Работает в режиме REPL (Read-Eval-Print Loop).
- Использует виртуальную файловую систему (VFS), загружаемую из XML-файла.
- Поддерживает базовые команды UNIX-подобной оболочки.
- Не взаимодействует с реальной файловой системой — все операции происходят в памяти.

## Поддерживаемые команды

| Команда | Описание |
|---------|----------|
| `ls`    | Показать содержимое текущей директории |
| `cd`    | Перейти в указанную директорию |
| `uname` | Вывести имя виртуальной системы |
| `tac`   | Вывести содержимое файла в обратном порядке |
| `mv`    | Переместить или переименовать файл |
| `exit`  | Выйти из эмулятора |

## Настройки и параметры запуска

Эмулятор принимает следующие аргументы командной строки:
- `--vfs <путь>` — путь к XML-файлу виртуальной файловой системы.
- `--script <путь>` — путь к стартовому скрипту (пакетный режим).
